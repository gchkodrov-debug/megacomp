# ADDENDUM — THE MANIFEST IS A MACHINE RESOURCE, NOT A DOCUMENT
Filed by the Captain, 2026-11-27 ~20:17 CT · Origin: Guardian production paper relayed by the founder · Binding on #143 (Gemini) and BUILD-ASSEMBLY-001 (Army)

The Assembly Asset Manifest (`assembly/ASSET_MANIFEST_2026-11-27.json`) is a **runtime resource**. Every build that places films or plates inside software — the Inner Chambers environments, the Grand Library assembly, the listings, the OS — consumes it programmatically:

1. **Load the JSON; never hand-copy asset lists.** The software resolves each world/room/product's assets from the manifest by subject/series.
2. **Rejected assets are hard-blocked.** Anything in the REJECTED series (e.g. MCR-0187 take 1) can never enter a finished experience — the consuming code refuses it, by rule, not by an engineer's memory.
3. **Missing assets surface as named gaps.** If a component declares an asset the manifest marks absent (MCR-0165) or a plate flagged below standard (Grand Library 2K), the build reports the gap by name in its delivery note. Silent substitution is a defect.
4. **Sound state travels with the film.** A film whose record shows WHISPER-UNFIXED is not placed as a finished element until its fix lands; the manifest is the source of that truth.

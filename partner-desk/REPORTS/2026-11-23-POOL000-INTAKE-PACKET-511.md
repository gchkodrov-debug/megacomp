**4. Exact Contents / Components in True Order**
This is a KIT (a set of records the buyer works through in order), not a performed process. Its genuine parts, in the order the buyer meets them — these are the parts the presentation separates and names:
*THE CORE WORKBOOK — `Fleet_Command_Center.xlsx` (8 sheets, in workbook order; 118 formula cells):*
1. **Start Here** — the 20-minute setup and the weekly habit, in plain language. WHAT IT DOES: puts the owner inside the system fast and sets the weekly rhythm everything else feeds.
2. **Agent Roster & Roles Register** — every agent as a staff record: name, job, model or tool, human owner, status, monthly spend cap; real spend and % of cap arrive by formula from the Cost Tracker. WHAT IT DOES: makes an agent drifting toward its cap visible before the invoice lands.
3. **Task Queue & Output Log** — every job the fleet touched: assignee, runbook, human review, Done / Failed / Redo; the done rate computes itself. WHAT IT DOES: gives every output a row, so nothing the fleet did is unrecorded.
4. **Cost Tracker** — every API charge, subscription and tool fee against its agent, by cost type. WHAT IT DOES: feeds the Roster and the Dashboard, so spend is never a surprise invoice.
5. **QA Scorecard** — sampled output checks against a written 1–5 rubric, with error types (Factual, Off-brief, Tone, Format, Policy); per-agent averages and error counts by formula. WHAT IT DOES: shows the agent whose quality is sliding in its own numbers, not in a customer complaint.
6. **Prompt & Runbook Library Index** — every prompt and runbook, its version, owner, review date, and status (Current / Needs update / Retired). WHAT IT DOES: makes the fleet's method an owned asset instead of text scattered in chat threads.
7. **Escalation & Failure Log** — every failure written down: what happened, severity, the SOP step that handled it, the prevention that landed in the runbook, open or closed. WHAT IT DOES: turns each failure into a fix with a paper trail.
8. **Weekly Review Dashboard** — the fleet in thirteen numbers, all by formula (agents, tasks, done rate, spend, cost per output, spend vs caps, QA average, open escalations), plus the kill / keep board. WHAT IT DOES: forces a decision and a written reason for every agent, every week.
*THEN, IN STANDARD:* 9. **The Worked EXAMPLE** — the same workbook pre-filled with one complete fictional month (Northbeam Outfitters, six agents, October 2026), labelled fictional on its face. WHAT IT DOES: teaches the system on a month whose every number reconciles before the buyer trusts it with his own. 10. **Setup Guide (PDF, 10 pages)** — the method sheet by sheet, the scoring rubric, the sampling plan, cap-setting arithmetic, the five failure patterns. 11. **Fleet Review One-Pager (PDF, 1 page)** — the printable weekly review sheet.
*PRO ADDS, IN ORDER:* 12. **Multi-Fleet Command Center** (workbook, 5 sheets incl. Start Here: Client Fleet Roster · Monthly Fleet Log · Fleet Roll-Up · Cross-Fleet Dashboard; 55 formula cells) — the agency layer: many client fleets, per-fleet roll-ups, and a dashboard that flags any fleet running below a 4.0 QA average. 13. **Capacity Planner** (workbook, 3 sheets: Agent Load Table · Add / Retire Decision Board; 412 formula cells) — assigned vs completed load, human review hours, and the add/retire rules printed on the sheet. 14. **DFY Install Blueprint** (workbook, 4 sheets: Client Intake, 14 fields · Install Checklist, 25 steps in 4 phases — Discovery · Access & Build · Guardrails & QA · Handover · Handover Pack, 10 items; 19 formula cells) — the exact install the house would run for a client, usable to self-install or to audit anyone hired to install.
Every workbook ships in Excel + Google Sheets versions, blank and worked-EXAMPLE. File counts: Standard 6 files · Pro 18 files.
